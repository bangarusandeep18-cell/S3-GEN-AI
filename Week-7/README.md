# Week 7 — Next-token probabilities with GPT-2

1. Create/activate `.venv`; install `python -m pip install -r requirements.txt`.
2. Run `python main.py`. The first run downloads GPT-2 weights and tokenizer files, so internet access and several hundred MB of disk space may be required.
3. Inspect `week7_probability_results.csv`.

The code uses `torch.inference_mode()` for inference and writes UTF-8 CSV output.
